This skill creates a design brief through structured conversation. You may skip steps if they are not necessary.

## Process

1. Ask the user for a detailed description of what they want to build, who it is for, and any constraints or ideas they already have.

2. Explore the existing codebase to understand the current state:
   - Scan for CSS variables/tokens, Tailwind config, UI framework themes, component directories.
   - Look for existing pages, layouts, and font loading patterns.

3. Interview the user to resolve every aspect of the design until reaching a shared understanding.
